# Security Policy / Аюулгүй байдлын бодлого

## Reporting a vulnerability / Эмзэг байдлыг мэдээлэх

If you discover a security issue, please **do not** open a public GitHub issue.

Instead, email **53986637+enkhbold470@users.noreply.github.com** with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact

Аюулгүй байдлын асуудлыг олвол нийтийн GitHub issue нээхгүйгээр дээрх имэйл рүү мэдээлнэ үү.

## Scope / Хамрах хүрээ

This project is a read-only scraper for public unegui.mn listings. It does not handle user credentials, payments, or private data.

Энэ төсөл зөвхөн unegui.mn-ийн нийтийн заруудыг уншдаг. Нэвтрэх мэдээлэл, төлбөр хүлээн авахгүй.
