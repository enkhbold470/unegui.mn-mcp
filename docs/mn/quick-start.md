## Шаардлага

- Node.js 18+ (`npx`)
- [uv](https://docs.astral.sh/uv/) (Python MCP серверийг ажиллуулахад)
- Python 3.12+

## NPX-ээр ажиллах (Хамгийн хялбар)

```bash
npx -y unegui.mn-mcp install
npx -y unegui.mn-mcp
```

## Эх кодноос ажиллуулах

```bash
git clone https://github.com/enkhbold470/unegui.mn-mcp.git
cd unegui.mn-mcp
uv sync
uv run unegui-mcp
```
